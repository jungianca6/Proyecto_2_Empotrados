# Proyecto_2_Empotrados

Pueden usar el comando que usaba el profe para configurar el entorno, y así poder usar Quartus en la terminal

```bash
cd ~/Proyecto_2_Empotrados
source src/scripts/env.sh
```
Con este comando, se abre la interfaz de Quartus, y así pueden entrar al Platform Designer
```bash
$ quartus &
```

Los scripts build-hw.sh, build-sw.sh, asi como los que están en /general y /nios, están copiados y pegados de los archivos de Jeff. Solo el env.sh es el que está moldeado y editado acorde a nuestro proyecto.
