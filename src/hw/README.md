# Proyecto_2_Empotrados

Primer sistema del Platform Designer, con un procesador Nios V, memoria RAM de 64KB, PIOs para switches, botones, leds y cuatro de los seis 7 segmentos. También un JTAG ya asignado al procesador.

Falta asignar pines. El archivo de1-soc-pines.qsf sirve como referencia como el pin planner de la FPGA.
